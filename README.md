# A.T. HOUSE · Private AI Office

ออฟฟิศจำลองส่วนตัว ภาษาไทย สำหรับจัดงานออกแบบบ้าน → ถอดปริมาณ → เตรียมตรวจโครงสร้าง ใช้ AI ผ่านการคัดลอกคำสั่งและนำคำตอบกลับมาเอง ไม่มี API ภายนอก ไม่มี dependency ภายนอก และไม่ต้องสมัครบริการเพิ่ม

## เปิดบน Windows

1. ติดตั้ง Node.js รุ่น LTS (20 ขึ้นไป) จาก https://nodejs.org ถ้ายังไม่มี
2. เปิดโฟลเดอร์นี้ใน PowerShell แล้วเรียก `npm start`
3. หน้าต่างแสดงพอร์ต 3000 และรหัสเข้าออฟฟิศ เปิดเบราว์เซอร์บนคอมที่พอร์ตนี้ แล้วใส่รหัส ห้ามแชร์รหัสกับบุคคลอื่น
4. บนมือถือที่อยู่ Wi-Fi เดียวกัน เปิดที่อยู่ IPv4 ของคอมตามด้วย `:3000` (ดู IPv4 ด้วย `ipconfig`) หาก Windows ถามเรื่อง Firewall ให้อนุญาตเฉพาะเครือข่ายส่วนตัว อย่าเปิดพอร์ตเราเตอร์ออกอินเทอร์เน็ต

คอมต้องเปิดโปรแกรมค้างไว้ มือถือจึงใช้งานได้ ข้อมูล HTTP ใน Wi-Fi ไม่เข้ารหัส ใช้เฉพาะเครือข่ายส่วนตัวที่เชื่อถือได้ ไม่มีการทดสอบบน Windows จริงจากสภาพแวดล้อม Linux นี้

กำหนดรหัสคงที่ใน PowerShell ได้ด้วย `$env:OFFICE_PASSWORD="รหัสที่คุณตั้งเอง"` ก่อน `npm start` หากไม่ตั้ง ระบบสุ่มรหัสใหม่เมื่อเปิดโปรแกรม เก็บรหัสไว้ในหน้าต่างโปรแกรม ไม่ส่งรหัสไปเว็บ AI

## วิธีใช้

- สร้างโครงการ พิมพ์โจทย์ เลือกตัวละคร แล้วสร้างงาน
- คัดลอกคำสั่งไป ChatGPT / Claude / Gemini ที่คุณใช้อยู่ แนบไฟล์ต้นฉบับในเว็บ AI เอง แล้วนำคำตอบมาบันทึก ระบบไม่ควบคุมเว็บ AI หรือบัญชีของคุณ
- เลือกอนุมัติก่อนส่งต่อ หรือส่งต่อทันทีที่บันทึกคำตอบ การส่งต่อสร้างงานรอคัดลอกให้ตัวละครถัดไป ไม่ได้สั่ง AI ทำงานเอง
- ดูแบบแนวคิด ปรับกว้าง/ลึก/ชั้น/ห้อง/งบ หมุนมวลอาคาร 3D และส่งออกผัง SVG ได้ แบบนี้มาจากค่าที่กรอก ไม่ได้แปลงข้อความ AI เป็นแบบอัตโนมัติ
- แฟ้มโครงการรองรับรูป PDF DWG Excel CSV สูงสุดไฟล์ละ 20 MB ไฟล์ DWG/Excel เก็บและดาวน์โหลดไปเปิดใน AutoCAD, SketchUp, Revit หรือโปรแกรมที่รองรับ ไม่มีการแก้ CAD ในเว็บ
- ถอดปริมาณและคำนวณโครงสร้างผ่านคำสั่งให้ AI ช่วยเตรียม ไม่ใช่เครื่องคำนวณโครงสร้างที่ผ่านการรับรอง ต้องตรวจผลโดยผู้ประกอบวิชาชีพก่อนก่อสร้าง

## ข้อมูลและสำรอง

เก็บงานที่ `data/state.json` และไฟล์แนบใน `data/files/` ร่วมกันทั้งมือถือและคอม ปิดเซิร์ฟเวอร์ก่อนคัดลอกทั้งโฟลเดอร์ `data` เพื่อสำรอง การส่งออก JSON มีเฉพาะข้อมูลโครงการ ไม่รวมไฟล์แนบ บัญชีเดียวสำหรับออฟฟิศส่วนตัว ยังไม่มีระบบผู้ใช้หลายระดับหรือแก้ไขพร้อมกันแบบสด ให้รีเฟรชเพื่อรับข้อมูลจากอีกเครื่อง และหลีกเลี่ยงแก้งานเดียวกันพร้อมกัน

## ตรวจสอบ

`npm test` ทดสอบ API จริง รวมรหัสเข้าออฟฟิศ สร้างโครงการ ส่งต่องาน ไฟล์แนบ และการเก็บข้อมูลหลังเปิดใหม่

ใช้ `PORT` เปลี่ยนพอร์ต และ `DATA_DIR` เปลี่ยนที่เก็บข้อมูลได้ โปรแกรมฟังบนทุก interface เพื่อรองรับ Wi-Fi
